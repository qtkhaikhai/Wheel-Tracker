Google Drive Sync
Save to Drive
Saves your data to WheelTracker/wheel-data.json in Google Drive. You'll be prompted to sign in with Google the first time. After that it saves automatically after every change.
Load from Drive
Pull the latest saved data from your Drive file. Use this when opening on a new computer or after using the app elsewhere.
Restore Last Snapshot
If a Drive load or other operation replaced your data unexpectedly, this restores the automatic snapshot taken just before the last overwrite. Only one snapshot is kept at a time.

Data Migration
Set Number Migration
One-time tool to assign correct set numbers to your existing trades based on wheel cycle boundaries (put assignment → call away = one set). A backup is downloaded automatically before any changes are made.
Danger Zone
Reset Everything
Wipe all trades, long positions, share prices, and settings. Returns the app to a completely fresh state — this cannot be undone.
